
# Installation on Chrome OS


      Go to settings and make sure linux mode is enabled.

      After confirming, go to official legacy launcher website, aka, llaun.ch

      Go to downloads, and click on Ubuntu.

      after clicking, install the .deb package.

      after installation is complete, go to files application.

      double click on file labled, TL_legacy.deb.

      hit install.

      it will install and may show an icon in your launcher.

      open app and create an account and enjoy!
